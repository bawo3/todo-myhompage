# ✅ My Todo — 개인 할 일 관리 홈페이지

🔗 **배포 주소**: https://bawo3.github.io/todo-myhompage/

---

## 🎯 주요 기능

| 기능 | 설명 |
|------|------|
| 할 일 관리 | 추가 / 완료 / 삭제, 우선순위(높음·중간·낮음) |
| 태그 시스템 | `#태그` 입력으로 자동 파싱, 태그별 색상 및 필터 |
| 마감일 / D-day | 날짜 설정 시 D-day 자동 표시, 기한초과 경고 |
| 반복 할 일 | 매일 / 매주 / 매월 자동 인스턴스 생성 |
| 대시보드 | 완료율, 우선순위 분포, 태그별·요일별 차트 |
| 내보내기 | JSON 백업 / CSV 저장 / 텍스트 복사 |
| 가져오기 | JSON 불러오기 (기존 데이터에 병합) |

---

## 🚀 실행 방법

별도 서버 없이 `index.html` 파일을 브라우저에서 바로 열면 됩니다.

```bash
# 로컬 실행
index.html 파일을 브라우저로 열기
```

---

## 📱 데이터 저장

모든 데이터는 **localStorage**(`td2`)에 저장됩니다.
브라우저 데이터 삭제 시 함께 삭제되므로 JSON 백업을 권장합니다.
